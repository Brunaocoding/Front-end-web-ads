Como configurar uma tag NFC

Aprenda a gravar e programar uma etiqueta NFC do zero, usando só o seu celular.

O que é uma tag NFC?

NFC (Near Field Communication) é uma tecnologia de comunicação por aproximação. Uma "tag" NFC é um adesivo ou cartão pequeno com um chip que consegue guardar informações, como um link, um texto ou um comando para o celular.

O que você vai precisar

  • Um celular com NFC (a maioria dos Android e iPhone a partir do 7)
  • Uma ou mais tags NFC em branco (fáceis de achar online)
  • Um aplicativo gravador de NFC, como o "NFC Tools"

Passo a passo

1. Ative o NFC do celular. Vá em Configurações → Conexões (ou Wi-Fi e redes) → ative a opção NFC.
2. Instale um app gravador. Baixe o "NFC Tools" na loja de aplicativos do seu celular.
3. Abra o app e toque em "Escrever". Escolha o tipo de conteúdo: link, texto, Wi-Fi, contato, etc.
4. Encoste o celular na tag NFC. Aproxime a parte de trás do celular da etiqueta até aparecer a confirmação de gravação.
5. Teste a tag. Encoste o celular novamente na tag (fora do app de gravação) para conferir se a ação configurada é executada.

Dicas rápidas

  • Tags mais baratas (NTAG213) guardam menos dados que as NTAG215/216
  • Evite colar a tag sobre metal, isso pode atrapalhar o sinal
  • Você pode bloquear a tag depois de gravada, para impedir reescrita
